# System Design Notes

Personal notes on system design topics.

## Usage

Sync runs automatically when you save a markdown note in Cursor, or run it yourself:

```bash
python3 scripts/sync_notes.py          # format + lint + refresh README
python3 scripts/sync_notes.py --check  # check only, no writes
python3 scripts/watch_notes.py         # watch folder and sync on every save
```
