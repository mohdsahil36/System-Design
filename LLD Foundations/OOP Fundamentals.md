What is OOPS?
- OOPS means organising a program around objects which contain data , functions and other things which they can do with each other .

For Eg. If we are building a bankign software instead of keeping random functions we abstract them according to work as Deposits(), Savings(), Fixed Deposits() , each containing code which helps us to work . OOPS is the process of getting these things together in a particular format.

Why is it required?
In case we do not pre define thing , then by each day the codebase will expand which has the chance of making the things messy and not understandable. OOPS tells us- "These things stay together!"

Simply, Data+Related Functions = Object (as decided by OOPS principles)

Why is it required for LLD?
- Because when we built end to end systems or even individual systems , then we have 2 questions to answer- 1. What exists in our system ? 2. What does each of them does ?
